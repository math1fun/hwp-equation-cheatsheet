앞부분의 줄 수가 바뀌어도 뒷부분이 밀리지 않습니다. 메뉴는 쪽 → 나누기입니다.

Alt+Shift+Enter구역 나누기 (구역마다 다른 쪽 설정 가능)
상용구 — 준말만 쓰면 본말이 입력됩니다
  • 편집: 입력 → 상용구 → 상용구 내용 (Ctrl+F3)
  • 적용: 준말을 쓰고 Alt+I
  • 순환 설정: 3 → ③ → ⑶ → … → 3 처럼 Alt+I를 반복해 누를 때마다 바뀌도록 준말과 본말을 이어 두면 편리합니다.
  • 저장과 불러오기는 편집 창 아래 버튼을 씁니다.
사용자 문자표 — 자주 쓰는 특수문자 한 번에 등록

문자표 열기는 Ctrl+F10. 저장과 불러오기 기능이 없으므로 다음 방법을 씁니다.

  1. 빈 문서에 자주 쓰는 문자를 한 문단으로 입력해 hwp로 저장
  2. 다른 컴퓨터에서 그 파일 열기
  3. 문자열 전체를 블록 지정하고 Ctrl+C
  4. 문자표 입력 창의 ‘사용자 문자표’ 탭 열기
  5. ‘문자 영역’ 추가
  6. ‘입력 문자’ 칸에 Ctrl+V
  7. ‘등록’ 버튼 누르기
바탕쪽 — 모든 쪽에 한꺼번에 넣기

쪽 → 바탕쪽에서 설정합니다. 구역 안의 모든 쪽에 글자, 이미지, 도형을 일괄 삽입하며 배경 이미지와 비슷하게 생각하면 됩니다. 문서 전체 또는 구역별로, 한 구역 안에서도 첫 쪽, 마지막 쪽, 홀수·짝수 쪽, 지정한 쪽에만 따로 적용할 수 있습니다.

삽입된 개체의 위치 — 조판 부호로 확인
  • 그림, 표, 쪽 번호, 감추기 같은 모든 개체는 글자처럼 논리적 위치를 가집니다. 보기 → 표시/숨기기 → 조판부호로 확인합니다.
  • 쪽 밖에 있어 클릭할 수 없는 개체는 조판 부호를 켜고, 개체가 놓인 위치에서 Ctrl+N, K를 누르면 편집됩니다. 쪽 번호와 감추기 설정을 바꿀 때도 같습니다.
  • 묶인 개체를 풀기 전에는 위치 속성의 ‘글자처럼 취급’을 해제하세요.
쪽 번호 매기기와 감추기
  • 쪽 번호는 첫 쪽부터 매겨집니다. 조판 부호를 켜고 첫 쪽의 ‘쪽 번호 매기기’를 잘라 중간에 붙이면 그 쪽부터 번호가 나타납니다.
  • 한 페이지에 ‘감추기’와 ‘쪽 번호 매기기’가 여러 개 들어가지 않게 조판 부호로 확인하세요.
  • 서식 변경: 스타일 이름 ‘쪽 번호’, 영문 이름 ‘Page Number’로 스타일을 만듭니다.
  • 머리말, 꼬리말, 바탕쪽에서도 마우스 오른쪽 클릭 → 쪽 번호 매기기로 넣을 수 있습니다.
  • 일부 쪽만 숨기기는 쪽 → 감추기, 임의 번호로 시작하기는 쪽 → 새 번호로 시작입니다.
